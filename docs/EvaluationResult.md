# EvaluationResult Model

This document explains the `EvaluationResult` data model.

## Purpose

This model captures the output of an "LLM-as-a-Judge" evaluation process, where one AI model evaluates the quality of outputs generated by another.

## Model Structure

Defined in `src/app/models.py`.

### Fields

-   **score** (`int`): A numerical score (1-5) indicating quality.
-   **rationale** (`str`): Explanation for the assigned score.

## Usage

Used in quality assurance tests (e.g., `test_quality.py`) to verify that generated profiles or therapy programs meet clinical coherence standards.
