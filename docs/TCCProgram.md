# TCCProgram Model

This document explains the `TCCProgram` data model.

## Purpose

The `TCCProgram` model represents a structured Cognitive Behavioral Therapy (CBT/TCC) program tailored to a specific character's profile.

## Underlying Theory

CBT (TCC in French) is a psycho-social intervention that aims to improve mental health. The program is structured into modules with specific objectives and activities.

## Model Structure

Defined in `src/app/models.py`.

### Fields

-   **title** (`str`): Title of the therapy program.
-   **global_objective** (`str`): The main goal of the therapy.
-   **modules** (`List[Module]`): A sequence of therapeutic modules.

### Sub-models

#### Module
Represents a phase in the therapy.
-   **title**: Module name.
-   **session_range**: Approximate sessions (e.g., "Sessions 1-3").
-   **objective**: Goal of this module.
-   **activities**: List of `Activity` objects.

#### Activity
Specific interventions.
-   **title**: Name of the activity.
-   **details**: Steps or description.

## AI Generation

This model is generated by an LLM which takes a `CharacterProfile` as input and designs a suitable therapy plan.
