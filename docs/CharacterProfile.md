# CharacterProfile Model

This document explains the `CharacterProfile` data model used in the application.

## Purpose

The `CharacterProfile` model represents a comprehensive psychological and career profile of a character. It is generated by the AI agent based on user interactions and analysis.

## Underlying Theory

The profile combines two major psychological frameworks:
1.  **DSM-5 Diagnosis:** Clinical diagnosis criteria for mental health disorders.
2.  **Holland Code (RIASEC):** A theory of careers and vocational choice based on personality types.

## Model Structure

The `CharacterProfile` Pydantic model is defined in `src/app/models.py`.

### Fields

-   **character_name** (`str`): The name of the character.
-   **profile_date** (`str`): The date the profile was generated (YYYY-MM-DD).
-   **overall_assessment_summary** (`Optional[str]`): A narrative summary of the clinical findings.
-   **holland_code_assessment** (`Optional[HollandCodeAssessment]`): detailed results of the RIASEC assessment.
-   **character_id** (`Optional[str]`): Unique identifier for the character.
-   **diagnoses** (`List[DiagnosisEntry]`): A list of clinical diagnoses identified.

### Sub-models

#### HollandCodeAssessment
Contains the detailed RIASEC scores and analysis.
-   **riasec_scores**: List of `HollandCode` objects (Theme, Score, Description).
-   **top_themes**: The top matching themes.
-   **summary**: Textual summary of the career assessment.

#### DiagnosisEntry
Represents a single clinical diagnosis.
-   **disorder_name**: Name of the disorder.
-   **dsm_category**: Category in DSM-5.
-   **criteria_met**: Specific criteria met.
-   **specifiers**: Severity or course specifiers.
-   **dsm_code**: The code (e.g., 300.02).
-   **functional_impairment**: Description of impairment.

## AI Generation

The data is generated by prompting a Gemini model with a system instruction that requires it to output JSON matching this schema. The `google-adk` library or `google-genai` client is used to enforce or guide the structure.
