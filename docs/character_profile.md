# Character Profile Model

The `CharacterProfile` model represents the core output of the clinical assessment process. It integrates psychiatric diagnosis (based on DSM-5), personality assessment (Big 5), and vocational interest analysis (Holland Code).

## Underlying Theory

### DSM-5 Diagnosis
The diagnosis component follows the **Diagnostic and Statistical Manual of Mental Disorders, Fifth Edition (DSM-5)**.
- **Criteria-based**: The AI analyzes the input narrative to identify specific behaviors and symptoms that match DSM-5 diagnostic criteria.
- **Specifiers**: It includes specifiers (e.g., severity, course) to provide a nuanced clinical picture.
- **Functional Impairment**: A critical part of diagnosis is understanding how symptoms affect the individual's daily life, work, and relationships.

### Purpose of the Model

The `CharacterProfile` Pydantic model serves as the central data structure for the application. It ensures that:
1.  **Structured Data**: The unstructured narrative input is converted into a queryable, validated format.
2.  **Interoperability**: This model is used as input for downstream tasks like TCC program generation and podcast script creation.
3.  **Validation**: Pydantic ensures that all required fields (like `diagnoses` and `profile_date`) are present and correctly typed.

## AI Generation Process

The profile is generated by a Large Language Model (LLM) (Google Gemini) using a specialized system prompt.

1.  **Input**: A raw text description of a character (e.g., a case study, a fictional character biography).
2.  **Prompting**: The system prompt (`get_system_prompt_profile` in `src/app/prompts.py`) instructs the LLM to act as a clinical psychologist.
    - It enforces JSON output adhering to the `CharacterProfile` schema.
    - It explicitly requires the output to be in French.
    - It mandates the listing of specific DSM-5 criteria met.
3.  **Parsing**: The JSON output from the LLM is parsed and validated against the `CharacterProfile` Pydantic class.

## Key Fields

- `character_name`: Name of the subject.
- `diagnoses`: A list of `DiagnosisEntry` objects.
    - `disorder_name`: Name of the disorder (e.g., "Trouble de la personnalité borderline").
    - `criteria_met`: List of specific symptoms identified.
    - `dsm_code`: Official code (e.g., "301.83").
- `holland_code_assessment`: Nested model for RIASEC scores.
- `ocean_assessment`: Nested model for Big 5 traits.
